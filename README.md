# EcoHabit – Green Habit Tracker

EcoHabit is a responsive, frontend-only website that encourages students to develop eco-friendly daily habits and contribute to a more sustainable campus environment.

## Features
- Track six daily eco-friendly habits.
- Mark habits as completed each day.
- Earn points for completing green activities.
- Monitor daily progress and streaks.
- Unlock achievements for consistent participation.
- Save habit progress automatically using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `ecohabit` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
EcoHabit can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Habit data is stored locally in the user's browser.
